# การจับคู่ตัวตนนักเรียนจากไฟล์นำเข้า

- รหัสนักเรียนเป็นข้อความที่ตรงกับทะเบียนโรงเรียน ระบบตัดช่องว่างรอบรหัสและรักษาเลขศูนย์นำหน้า `00123` และ `123` จึงเป็นคนละรหัส เทมเพลตตั้งคอลัมน์นี้เป็น Text
- ไฟล์เดิมที่เก็บรหัสเป็นตัวเลขจำนวนเต็มในรูปแบบธรรมดาใช้ได้เมื่อรหัสที่อ่านได้และเลขประจำตัวตรงกับนักเรียนคนเดียวกัน หากเป็นนักเรียนใหม่ ไม่มีเลขประจำตัว หรือเซลล์ใช้สูตร รูปแบบเติมศูนย์ หรือเกินความแม่นยำ 15 หลัก ให้ตรวจทะเบียนและกรอกรหัสเป็นข้อความ ระบบไม่เติมศูนย์เอง
- หากรหัสนักเรียนหรือเลขประจำตัวซ้ำในชุดเดียวกัน ระบบปฏิเสธแถวที่ซ้ำทั้งหมด ผู้ใช้นำเข้าแถวอื่นที่ผ่านเงื่อนไขได้
- เมื่อรหัสนักเรียนและเลขประจำตัวตรงกับเรคอร์ดเดียวกัน ระบบใช้ `Student.id` เดิม เลขที่มีเจ้าของคนอื่นหรือขัดกับเลขเดิมต้องตรวจสอบ ช่องว่างไม่ล้างเลขเดิม
- เมื่อไม่มีเลขประจำตัวที่ตรงกัน ระบบเทียบชื่อและนามสกุลหลังปรับช่องว่าง ตัวพิมพ์ และรูปแบบ Unicode ถ้ารู้เพศกำเนิดทั้งสองฝั่งและข้อมูลต่างกัน ต้องตรวจสอบ การสะกดต่างหนึ่งอักขระในชื่อหรือนามสกุลต้องมีอีกส่วนตรงกัน และต้องทราบเพศกำเนิดที่ตรงกันกับอายุที่สอดคล้องทั้งสองฝั่ง
- อายุเท่ากันหรือเปลี่ยนหนึ่งปีรองรับการกรอกซ้ำและความต่างตามวันเกิด เมื่อเปลี่ยนเกินหนึ่งปี ระบบเทียบช่วงเวลาระหว่างวันเริ่มเทอมของผล PHQ-A ที่บันทึกล่าสุดกับเทอมที่กำลังนำเข้าและยอมให้คลาดได้หนึ่งปี หากไม่มีเทอมอ้างอิงหรืออายุเปลี่ยนไม่สอดคล้อง จะส่งให้ตรวจสอบ วันเริ่มเทอมเป็นเพียงบริบทของข้อมูล อายุในโปรไฟล์อาจเคยถูกแก้ด้วยมือและไม่มีวันเกิดให้ใช้ยืนยัน

เมื่อระบบแจ้งให้ตรวจตัวตน ให้ตรวจทะเบียนต้นทางและใช้หน้าจอแก้ไขโปรไฟล์ตามสิทธิ์ก่อนนำเข้าอีกครั้ง นักเรียนที่ใช้รหัสเดียวกันและมีข้อมูลที่ตรงกันทุกส่วนยังอาจแยกไม่ออกหากโรงเรียนนำรหัสกลับมาใช้ใหม่
